# ALGORITHMS

The algorithms in this GitHub repository are for personal/learning purposes and may not be perfect or useful for real-world problems. Use them at your own risk!

**BINARY SEARCH ALGORITHM**
A simple algorithm to search for a specific value by repeatedly dividing the sorted list in half and comparing the target value to the middle element. (INT ONLY)

**GENETIC ALGORITHM**
A simple algorithm that generates random potential solutions and evolves them over time using operations like crossover (combining traits of the best solutions) and mutation (alternating 1 number of the string).
